# 香港社福導航 · 六站 UX 實測

以「居家長者需要日常起居照顧，希望比較資助及自費服務」為情境，記錄六個參考網站的實際操作，並提出香港社福導航首版的設計建議。研究日期為 2026 年 11 月 23 日。

| 檔案 | 使用方法 |
|---|---|
| [Claude 交接報告](香港社福導航_Claude交接報告.md) | 可直接在 GitHub 閱讀，亦可下載並上載到 Claude。包含測試範圍、逐站比較、設計優先次序及結果卡示例。 |
| [六站 UX 實測報告](香港社福導航_六站UX實測報告.html) | 下載 HTML 後在瀏覽器打開。內含 12 張可展開的截圖，不需另外下載圖片。 |

參考網站包括照顧者資訊網、社聯智識揀、社署長者資訊網、港大一擊通、GOV.UK 及 NHS。報告分別標示頁面實測、設計判讀和建議，香港服務的資格及安排應以報告所連結的官方來源核實。
